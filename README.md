# Vue Demo - 用户管理系统（前端）

配套 Spring Boot 后端的 Vue 3 前端，实现登录、用户列表、增删改查。

## 技术栈

- **Vue 3** - 前端框架
- **Vue Router 4** - 路由
- **Axios** - HTTP 请求
- **Element Plus** - UI 组件库
- **Vite** - 构建工具

## 功能

- 登录（JWT 认证）
- 用户列表
- 新增用户（弹窗表单）
- 编辑用户（弹窗表单）
- 删除用户（确认弹窗）
- 退出登录
- Token 自动携带
